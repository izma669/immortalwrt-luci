简介与客户端下载

VirtualHere USB Server 用途：可实现通过网络挂载 USB 设备。

从 官网 下载对应平台的客户端程序运行并联机。

启用 / 停用（总开关）

开机自启：获取中...

开关保存在 /etc/config/vhusbd 的 enabled 选项中。 停用时会立即停止服务并移除 /etc/rc.d 开机启动项；即使启动项被重新加回来， /etc/init.d/vhusbd 在启动时也会再次检查该选项，为 0 时直接拒绝启动。
